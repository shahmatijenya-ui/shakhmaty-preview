# Шахматы Женя — личная тренировка

https://shahmatijenya-ui.github.io/shakhmaty-preview/

Полный интерфейс личного тренера: ежедневные задачи, разбор партий,
учебные материалы, дебютные планы и декоративная анимация «Бой с тенью».
Игра «Бой с тенью» пока выключена.

Для доступа к личной тренировке открой Telegram-бота:
https://t.me/ShakhmatyZhenyaCoachBot?start=site
и используй кнопку «Моя тренировка» или команду `/site`.

GitHub Pages обслуживает весь интерфейс. Авторизация, Stockfish, партии
и прогресс работают на отдельном сервере. Его актуальный публичный адрес
записывается в `backend.json` автоматически при восстановлении туннеля.

Здесь нет базы партий, ключей доступа, персональных результатов и серверного кода.
Здесь размещена готовая сборка интерфейса. Шрифты распространяются с лицензиями в `fonts/`.
