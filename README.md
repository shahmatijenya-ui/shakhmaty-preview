# Бой с тенью — публичный просмотр

https://shahmatijenya-ui.github.io/shakhmaty-preview/

Отдельная статическая страница с готовой анимацией. Цикл 14 секунд, 1280×720,
30 кадров/с, без звука. Игра «Бой с тенью» выключена; входа в матч на странице нет.

Видео приостанавливается вне экрана и в скрытой вкладке. При системном уменьшении
движения показывается неподвижный кадр; анимацию можно включить вручную.

Личный тренер с авторизацией, задачами и разборами работает отдельно:
https://shakhmaty-eta.vercel.app

Здесь нет базы партий, ключей доступа, персональных результатов и серверного кода.
Шрифты распространяются с их лицензиями в `fonts/`.
